# Northstar Care Operations

A static, browser-ready prototype for the Scenario 5 hospital resource planning challenge.

## Run

Open `index.html` in a browser. No package installation or build step is required.

## Prototype scope

- Demand and capacity overview using illustrative sample data
- 24-hour, 7-day, and 30-day forecast views
- Bed, ICU, emergency department, and staffing utilization
- Operational recommendations and alerts
- Scenario planning dialog and CSV snapshot export

All dashboard values are synthetic and for demonstration only. The prototype does not connect to hospital systems or perform live forecasting.
